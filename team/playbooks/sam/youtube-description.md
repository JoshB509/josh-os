# YouTube descriptions

Josh's default for every YouTube video description, whether drafting for review or preparing a description update:

1. Start on line one with ✅, followed by the primary call to action in plain language and its verified link on the same line. No heading, intro, or other text above it. Use the offer the video actually points to and the Linklr link that belongs to that video and placement. Never borrow another video's tracking link. If missing, use a clearly labeled placeholder in the draft only and flag it; never publish a placeholder.
2. Put a blank line after the CTA so it stands on its own above the fold. Then write one short, search-friendly paragraph with the video's actual topic and natural search terms. Don't repeat the CTA or add testimonials, hype, or a long recap. Keep optional links out of the way unless Josh asks for them.
3. Put chapters last. Preserve timestamps already verified against the final export. If there are only proposed chapter labels, leave them as a draft and flag missing timestamps rather than guessing.

Josh can override this for a particular video. Keep the usual review and approval steps.
