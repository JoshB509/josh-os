DaJoshiResolve Studio — local project workspace
Version 0.2.0-studio; editing engine remains 0.1.0-alpha unchanged.

OPEN
Use the existing DaJoshiResolve (Alpha) desktop shortcut, or run
E:\Videos\DaJoshiResolve\DaJoshiResolve.exe.
It opens a dedicated Chrome/Edge app window backed by a local-only server.
No account, API key, paid inference or publishing connection is used.
The sidebar's Open classic editor button opens the previous native editor.
Dropping source files onto the desktop launcher also opens that classic editor.

WORKFLOW
1. New video creates a project. Cancel creates nothing.
2. Use Overview for notes and a planned publication date.
3. Add alternative titles and star the chosen title.
4. Import PNG, JPEG or WebP thumbnails. Images are copied into this app's Data
   folder; originals are never moved. Add up to three, arrange them with the
   left-arrow buttons, and choose a title underneath each comparison card.
5. Paste/write the script in Script. Save project (or Ctrl+S) commits changes.
6. Drag a board card to a visible stage, or choose any stage inside a project.
   The board scrolls horizontally to show all stages.
7. Editing accepts local source paths, JSON/CSV shots, an HTML deck, and optional
   audio/reference/transcript. Browse opens this app's own file chooser.
   Build editable draft saves the project and starts the existing worker.
   Starting again during an active run returns the same run, not a duplicate.
8. Run history shows actual worker status. Cancel safely requests cancellation;
   Resume saved run reuses the same request and completed stages. A changed
   editing engine/request is rejected by the editor's own cache identity guard.

DATA
Projects, revisions, scripts, title choices, thumbnail choices and run history:
E:\Videos\DaJoshiResolve\Data\studio.sqlite
Copied thumbnail images: Data\assets
Script snapshots for editing: Data\scripts
Worker console logs: Data\logs
Editing outputs: Runs\Studio-<unique id>
Project JSON export is a portable text snapshot, NOT a full media backup.
Archiving only hides a project from the board; Archive can restore it.
Closing the app window does not cancel a running edit. Its local worker and
small local server may continue until Windows exits. Reopening reconnects.
If two windows edit a project, stale saves are rejected instead of overwriting
the newer version; reload the project to recover the latest saved version.

LIMITATIONS
Publication dates are local planning only; nothing is automatically uploaded.
No script generation, AI API integrations, email/document discovery or accounts.
The editor still has its original alpha limitations: arbitrary/VFR rate export,
native Premiere import/effects/playback, and full editorial quality are not proven.
The scheduler does not change the editor's selection algorithm or render results.
Rust was unavailable; no Rust/build dependencies were installed. The app uses
the installed C# launcher, local Python, SQLite and an installed Chrome/Edge.
The Python runtime and cached Whisper model still live in the earlier work
environment listed in settings.json; moving/removing that environment will break
the launcher/editor until those paths are updated.
Reference screenshot materialization failed because the supplied Library helper
uses os.setxattr, unavailable on Windows. Descriptions were accessible, but their
original pixels were not inspected. Demo screenshots use labelled test thumbnails.
